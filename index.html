Ayuda y Documentación Allmiibo

settings Opciones del Dispositivo

  • Emulador de Amiibo: Permite seleccionar y emular un Amiibo individual guardado en el almacenamiento (archivo .bin o .nfc). El Allmiibo se comportará físicamente ante la consola como esa tarjeta.
  • Base de datos de Amiibo: Utiliza la base de datos interna y la clave key_retail.bin para generar y emular Amiibos al vuelo sin necesidad de tener el archivo .bin cargado individualmente.
  • AmiiboLink: Modo de enlace especial compatible con la app móvil AmiiboLink para seleccionar y descargar Amiibos de forma rápida mediante Bluetooth.
  • Emular etiqueta RFID: Emulación general de etiquetas NFC/RFID estándar para clonación o pruebas más allá de los Amiibos de Nintendo.
  • Bluetooth: Activa el Bluetooth para enlazar el dispositivo con este Gestor Web o con aplicaciones móviles para actualizar archivos y claves.

question_mark Preguntas Frecuentes (FAQ)

¿Cómo consigo los últimos Amiibos (como Splatoon Raiders)? Puedes descargar los últimos archivos .bin desde el Google Drive de la comunidad haciendo clic en este enlace y luego subirlos a tu Allmiibo usando el botón Subir Archivos en la pestaña del Explorador Local.
¿Por qué hay tantos Amiibos de Animal Crossing y algunos sin nombre? Animal Crossing cuenta con 400 cartas estándar, las series de Sanrio, Amiibo Festival y las 91 cartas especiales de **Happy Home Designer Items** (que aparecen abajo como [HHD] Items - XX). Estas últimas corresponden a muebles y diseños del juego y no a personajes/aldeanos concretos, por lo que no tienen nombres estándar.
¿Cómo actualizo la clave key_retail.bin automáticamente? Haz clic en el botón Auto-llave en la barra lateral. Se descargarán las llaves necesarias de repositorios comunitarios públicos de GitHub y se fusionarán en el archivo de 160 bytes necesario en la raíz del Allmiibo para habilitar la encriptación.
cloud_download Auto-actualización de Llaves

Se descargarán los archivos criptográficos desde un repositorio comunitario de GitHub, se unirán automáticamente en memoria para obtener el archivo key_retail.bin (160 bytes) y se subirán a tu Allmiibo.
